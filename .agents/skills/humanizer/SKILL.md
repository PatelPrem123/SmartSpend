# Humanizer Skill

Refactors copy, error messages, and documentation into natural, direct human communication.

## Rules
- Strip AI cliches ("delve into", "tapestry", "beacon of hope", "crucial role", "vital importance").
- Prefer active voice and direct sentences.
- Make error messages empathetic, clear, and actionable: tell the user what happened and what to do next.
- Keep comments concise and focused on *why* non-obvious logic exists, not *what* standard code does.
