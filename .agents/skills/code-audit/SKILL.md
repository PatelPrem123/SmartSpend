# Master Code Audit & Testing Skill

This skill enforces deep, evidence-based code reviews and quality transformations.

## Workflow

1. **Pre-Review Inspection:** Inspect the codebase without assuming code is correct.
2. **Quality Audit:** Evaluate readability, clean code principles, dead code, and naming conventions.
3. **Logic & Edge Cases:** Test empty inputs, null/undefined, boundary conditions, race conditions.
4. **Security Analysis:** Check NoSQL injection, XSS, CSRF, BOLA/IDOR, confidential data leakage.
5. **Backdoor Audit:** Search for `BYPASS_AUTH`, hardcoded credentials, debug endpoints, or mock tokens.
6. **Execution Verification:** Run actual tests via terminal and capture real exit codes. Never invent test results.
