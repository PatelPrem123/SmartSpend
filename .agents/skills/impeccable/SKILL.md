# Impeccable UI Polish Skill

Ensures all frontend views in HelpDesk Hub meet high visual standards.

## Audit Checklist
- Padding & Margin Rhythm: Uniform 4px grid spacing (`p-2`, `p-4`, `p-6`).
- Contrast Ratios: Minimum 4.5:1 for normal text, 3:1 for large text (WCAG AA).
- Color System: Consistent token usage (no arbitrary hex colors scattered in templates).
- Empty States: Meaningful illustrations/icons and action buttons for zero-ticket queues.
- Loading Skeletons: Pulse skeletons matching exact table and card dimensions.
