# UI UX Pro Max Skill

Guides the generation of enterprise-grade interfaces for HelpDesk Hub.

## Design System Guidelines

- **Palette:** Slate backgrounds (`bg-slate-900`, `bg-slate-50`), Deep Royal Blue primary (`#1E40AF`), Vibrant Blue secondary (`#2563EB`).
- **Typography:** Inter or system sans-serif font stack. Clear visual hierarchy with `text-xs`, `text-sm`, `text-base`, `text-lg`, `text-xl`.
- **States:** Hover, focus-visible with clear ring offsets (`focus-visible:ring-2 focus-visible:ring-blue-500`), disabled states with opacity.
- **Accessibility:** WCAG AA compliance, semantic button/nav/main landmarks, ARIA labels on icon buttons.
